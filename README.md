# 智能中药开方系统

一款本地化、图形化的 **AI 中药开方 / 识别 / 调方平台**（基于 PySide6 的桌面应用，已移除 RPA 引擎）。

本地 GUI 直连 DeepSeek 云端大模型，覆盖中医场景下的完整工作流：
根据患者主诉、病史、体质等自动生成中药方；识别药方中各味药材的性味归经、功效与注意事项；
并通过对话式 AI 助手持续解释与调整药方。开方与识别结果均可一键导出为 PDF。

## 功能特性

- **药方开方**
  完整表单收集病情信息（主诉/现病史/当前用药/年龄性别/体质/过敏史/舌象脉象/经带/生活习惯），
  AI 生成结构化药方（方名、立法思路、剂数、煎服法、禁忌、加减说明、药材表格），
  卡片化展示，支持导出 PDF、一键带入 AI 助手继续调整。
- **药方识别**
  逐项录入药材（药名 + 剂量 + 单位），输入时接入内置 **约 340 味常用中药库**，
  支持中文 / 全拼 / 首字母模糊联想下拉（键盘上下键选词、回车填入，兼容中文输入法）；
  也可整方一次性粘贴。AI 逐味解析性味归经、功效与注意，并给出配伍解析与煎服确认，支持导出 PDF。
- **AI 助手**
  对话式聊天，内置「资深中医师」系统提示词；富文本渲染 Markdown（标题/加粗/表格/列表）；
  完整对话历史随请求发送，可从开方/识别结果一键带入当前药方继续追问。
- **设置**
  多套界面风格 + 深浅色热切换；AI 模型向导式新增/管理/删除（保存前自动校验 API Key 有效性与网络连通性）。
- **关于**：项目简介与免责声明。

## 快速开始

```bash
pip install PySide6 reportlab
python main.py
```

首次使用前，需先在「设置 → AI 模型配置」中添加模型并填写 DeepSeek API Key
（保存前自动校验有效性与网络连通性）。当前接入 DeepSeek 云端模型（`deepseek-v4-flash`）。

> 方向依据：见 `PRD.md`（含「待澄清细节」，后续逐条确认）。

## 项目结构

```
zy_rpa/
  main.py             # GUI 唯一入口（python main.py）
  PRD.md              # 产品需求文档（含待澄清细节）
  src/
    core/             # 应用配置(config)、主题(theme)、用户偏好(user_config)、
                      # AI 客户端(ai_client)、DeepSeek 客户端(deepseek_client)、
                      # 提示词(ai_prompts)、MD 解析(md_parser)、PDF 导出(pdf_export)
    ui/               # 主窗口(window)、各页面(prescribe/recognize/assistant/settings/about)、
                      # 配置向导(model_wizard)、共享组件(pagekit/dark)
    data/herbs.py     # 约 340 味常用中药材库（名称/拼音/首字母）与 search() 模糊匹配
  Data/               # 动态数据目录（AI 生成/导出产物，不入版本库）
```

## 技术栈

- **UI**：PySide6（Qt 桌面 GUI）
- **AI**：DeepSeek 云端大模型（直连 API，无本地 server 链路）
- **PDF**：reportlab
- **解析**：轻量 Markdown 状态机解析器（`md_parser`），将模型输出归一为结构化数据
- **搜索**：内置中药材库的本地中文/拼音/首字母模糊匹配

## 数据与隐私

- 用户偏好（界面风格/深浅色）持久化于 `用户主目录/zy_rpa/config.json`。
- AI 生成/导出产物统一放根目录 `Data/`。
- AI 交互涉及患者症状/病史上传云端模型，实际使用请注意隐私与合规。
