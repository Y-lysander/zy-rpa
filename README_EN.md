# Smart TCM Prescription System

A local, GUI-based **AI Traditional Chinese Medicine (TCM) platform** that generates, analyzes and adjusts herbal prescriptions — built on PySide6 (RPA engine removed).

A local desktop GUI dials directly into the DeepSeek cloud LLM to cover the full TCM workflow:
generate herbal prescriptions from the patient's chief complaint, history, constitution, etc.;
analyze each herb's nature & flavor, meridian tropism, effects, and cautions; and
keep refining prescriptions through a conversational AI assistant. Both prescription and
analysis results can be exported to PDF in one click.

## Features

- **Prescription Generation**
  A complete form collects patient info (chief complaint / history / current meds /
  age & gender / constitution / allergies / tongue & pulse / menstrual & lifestyle).
  The AI returns a structured prescription (name, principle, dosage count, decoction
  method, contraindications, modifications, herb table) rendered as cards, with PDF
  export and one-click handoff to the AI assistant for further tuning.
- **Prescription Analysis**
  Enter herbs row by row (name + dose + unit) with fuzzy suggestions from a built-in
  **catalog of ~340 common Chinese herbs** supporting Chinese / full pinyin / initials
  matching and an in-place dropdown (arrow keys to select, Enter to fill, Chinese IME
  friendly); or paste a whole prescription at once. The AI analyzes each herb's nature,
  flavor, meridian, effects and cautions, plus combination analysis and decoction
  confirmation — exportable to PDF.
- **AI Assistant**
  Conversational chat backed by a "senior TCM physician" system prompt; Markdown-rich
  rendering (headings / bold / tables / lists); the full history is sent with each request,
  and the current prescription can be pulled in from the generate/analyze pages.
- **Settings**
  Multiple UI styles + light/dark hot switching; wizard-based add/manage/delete of AI
  models (API Key is verified for validity and network connectivity before saving).
- **About**: project intro and disclaimer.

## Quick Start

```bash
pip install PySide6 reportlab
python main.py
```

Before first use, add a model and fill in your DeepSeek API Key under
「Settings → AI Model Configuration」(validity and connectivity are checked on save).
Currently connects to the DeepSeek cloud model (`deepseek-v4-flash`).

> Rationale & open questions are tracked in `PRD.md`.

## Tech Stack

- **UI**: PySide6 (Qt desktop GUI)
- **AI**: DeepSeek cloud LLM (direct API, no local server component)
- **PDF**: reportlab
- **Parsing**: a lightweight Markdown state-machine parser (`md_parser`) that normalizes model output into structured data
- **Search**: local fuzzy matching over the built-in herb catalog (Chinese substring / pinyin / initials)

## Data & Privacy

- User preferences (style / light-dark) are persisted to `用户主目录/zy_rpa/config.json`.
- AI-generated/exported artifacts are stored in the root `Data/` directory.
- AI interactions upload patient symptoms/history to the cloud model — be mindful of privacy and compliance.
